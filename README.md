# mathematical_rebus
Программа, которая принимает на вход числовой ребус в виде строки и возвращает соответствующее валидное арифметическое выражение в форме строки.

Пример входных и выходных данных:

Вход: SEND + MORE = MONEY  
Решение: 9567 + 1085 = 10652

Вход: BE + BE = MOO  
Решение: 72 + 72 = 144

Параметры:  
•	Все буквы в верхнем регистре;  
•	Каждой букве может соответствовать только одна цифра;  
•	Ведущие нули не допускаются;  
•	В качестве арифметического действия используется только операция сложения «+»;  
•	Допустимое количество слагаемых в левой части выражения – от 2 до 7 включительно;
